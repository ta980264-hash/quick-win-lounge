# TP Lottery Hub

Create a modern, responsive, mobile-first Web Application for a gaming and lottery platform named "TP LOTTERY". 



### Color Palette & UI/UX Style:

- Primary Color Scheme: Dark/Modern Theme using Black, Pure White, and Vibrant Accent Red (#E50914 or similar bold red).

- Background: Sleek dark/black UI with white readable typography and red buttons/accents for interactive elements.

- Clean mobile view layout (App-like navigation with bottom navigation bar).



### Core Navigation (Bottom Tab Bar):

1. Home Tab: Game categories (Win Go, TRX Win Go), Banners, Announcement Ticker, Quick Wallet Overview.

2. Activity Tab: Daily bonuses, sign-in rewards, gift redemption codes.

3. Promotion Tab: Referral link generation, Agent tier summary, Invitation code copy, Subordinate statistics.

4. Wallet Tab: Balance overview, Deposit option, Withdrawal option, Transaction History.

5. Account Profile Tab: User Profile Header (UID, VIP status), Safe Vault balance, Game History, Account Settings.



### Games to Implement (Interactive Prototypes/Mockups):

1. Win Go (1 Min, 3 Min, 5 Min options):

   - Real-time countdown timer.

   - Betting panel: Select Green, Violet, Red, or Numbers (0-9), Big/Small choices.

   - Betting modal to enter bet amounts and confirm.

   - Live simulated result history table showing Period Number, Result Number, Big/Small, and Color indicator.



2. TRX Win Go:

   - Similar rules to Win Go, but displaying simulated TRX Hash Value verification blocks for result transparency.

   - Interactive timer and color/number selection board.



### Authentication & Mock Features:

- Login / Register Page (Phone number with country code selection and password setup).

- Mock Wallet System: Display user balance, working Deposit and Withdrawal modal forms (for simulation/MVP testing).

- Real-time mock data for Game Results, Timer Countdowns, and Balance updates upon placing mock bets.



Build this application using React, Tailwind CSS, Lucide icons, and state management so the game timer, betting options, result generations, and wallet balance deduct/reward flow function seamlessly in the frontend MVP demo.
